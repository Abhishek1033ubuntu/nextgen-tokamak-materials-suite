Contributions, bug reports, feature enhancements, and dataset extensions from the nuclear engineering, high-entropy alloy, and computational materials science communities are highly encouraged.How to Contribute:
Fork the Repository: Click the Fork button at the top right of this page.

Create a Feature Branch:
```
git checkout -b feature/NewPhaseCandidate
```
Commit Your Enhancements:
```
git commit -m "Add new candidate for Phase 2 wall screening"
```
Push & Open a PR: Submit your Pull Request against the main branch with attached simulation logs.
For major architecture proposals or institutional partnerships, please start a thread in GitHub Discussions.
